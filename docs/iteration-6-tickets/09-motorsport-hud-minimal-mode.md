## Parent

[Iteration 6 specification #50](https://github.com/Alred21/apex-bite/issues/50)

## What to build

Restyle the HUD into a sleek, low-profile GRID-inspired motorsport overlay with crisp tabular telemetry while keeping all existing controls directly reachable in Full mode, and add a one-key toggle for Minimal cockpit/timing-only driving mode.

## Acceptance criteria

- [ ] Top controls, timing center, Circuit minimap, Corner Execution Card, and bottom driver telemetry cluster adopt a compact, low-profile motorsport layout that increases unobstructed 3D viewport area.
- [ ] Every existing HUD control, button, selector, meter, and dialog remains directly visible and interactive in default Full mode without hiding behind extra drawers.
- [ ] Helmet Cam compact telemetry continues to keep the lower-center hands and F1 steering yoke unobstructed across standard laptop and desktop viewports.
- [ ] Pressing `[H]` or clicking the HUD toggle switches cleanly between Full and Minimal (timing and driving telemetry only) HUD modes without interrupting driving inputs or dialog shortcuts.
- [ ] Existing browser HUD layout and integration checks pass cleanly alongside verification of the Minimal mode toggle.
