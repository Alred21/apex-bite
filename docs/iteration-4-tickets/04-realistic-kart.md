## What to build

Drive and compare ghosts using a more convincing rental-Kart model with coherent proportions, bodywork, tires, steering components, and materials.

## Acceptance criteria

- [ ] Inspect actual appropriately licensed free Kart assets first for geometry, source/license, materials, fit to existing physical dimensions, steering compatibility, and browser cost. Adapt suitable assets or author missing geometry; retain sources, license, and attribution.
- [ ] Improve visible Kart realism in both cameras while preserving collision dimensions, physics, speed limits, and Circuit geometry.
- [ ] Use the shared visual definition so both ghost types acquire the updated Kart automatically; keep an occupied usable model with the existing driver until its dedicated refinement.
- [ ] Calibrate wheel scale and camera framing coherently; retain field-of-view and camera-comfort controls and clear track sightlines.
- [ ] Produce matching iteration-3/proposed in-game views and steering motion for early visual review; report geometry/material/texture and warmed-rendering costs against the existing 60 FPS target.
- [ ] Preserve steering animation and independent ghost materials/fading. Complete relevant browser checks, type checking, and build; no paid assets or broad venue changes.
